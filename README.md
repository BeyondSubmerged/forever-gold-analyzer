# Forever Gold Analyzer

**A World of Warcraft: Forever crafting and Auction House profitability analyzer.**

Forever Gold Analyzer is a personal, noncommercial software project designed to help players identify potentially profitable crafting opportunities in the World of Warcraft: Forever economy.

The application is currently being developed as a locally hosted Python web dashboard.

## Project Features

- **Auction House Analysis:** Import locally collected Auctionator pricing and supply data.
- **Crafting Profitability:** Calculate material costs, estimated selling proceeds, profit margins, and return on investment (ROI).
- **Profession Tracking:** Track character professions, skill levels, and learned recipes.
- **Opportunity Discovery:** Identify potentially profitable recipes based on available market data.
- **Market Risk Assessment:** Consider historical prices, competing supply, and estimated profitability.
- **Recipe Research:** Explore crafting recipes, required materials, and output quantities.

All profitability calculations are estimates based on historical Auction House data. Actual sales and profits are not guaranteed.

## Data Sources and Attribution

### ForeverDB

[ForeverDB.net](https://foreverdb.net/) is being evaluated as a reference data provider for World of Warcraft: Forever item identification, crafting recipes, and profession information.

The project intends to use the ForeverDB API for item ID lookups, recipe information, and reference data validation.

**Data attribution:** [ForeverDB.net](https://foreverdb.net/)

Where ForeverDB data is incorporated into the application, visible attribution and a link to ForeverDB will be provided in accordance with its API terms.

### Auctionator

Auction House pricing and supply information is collected locally using the Auctionator addon.
